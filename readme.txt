📊 Dashboard Commercial 2015-2018
📝 Description
Dashboard interactif d'analyse des performances commerciales développé avec Tableau Public. Visualisation complète des ventes, segments clients, satisfaction et répartition géographique sur 4 ans.

🎯 Objectifs

Suivre l'évolution des ventes et identifier les tendances
Analyser la satisfaction client par note
Comparer les segments de marché (Entreprise, Grand Public, PME)
Visualiser la distribution géographique des ventes
Identifier les catégories de produits performantes

📈 Composants du Dashboard
1. Évolution Temporelle des Ventes

Type : Line Chart
Période : 2015-2019
Insight : Croissance continue avec pics saisonniers
Tendance : Forte hausse entre 2018-2019

2. Carte Géographique

Type : Map interactive
Pays visibles : France, Allemagne, Espagne, Italie
Top région : France (858 931,08 €), Allemagne (628 840,03 €)
Utilité : Stratégie d'expansion géographique

3. Performance par Catégorie

Type : Bar Chart horizontal
Catégories :

Produits technologiques : ~800K €
Fournitures de bureau : ~800K €
Mobilier : ~600K €


Distribution : Équilibrée entre les 3 catégories

4. Segments Clients

Type : Bubble Chart (bulles proportionnelles)
Segments :

Grand public : Plus gros segment (bulle la plus grande)
Entreprise : Segment important
Petite et moyenne entreprise : Plus petit segment


Utilité : Ciblage commercial et allocation ressources

5. Satisfaction Client

Type : Bar Chart horizontal avec code couleur
Distribution :

🟢 Notes 4-5 : ~40-50 clients
⚫ Notes 2-3 : ~30-40 clients
🔴 Notes 0-1 : ~50-60 clients


⚠️ Alerte : Forte proportion de clients insatisfaits


🔍 Insights Clés
✅ Forces

Croissance soutenue : Ventes en augmentation constante
Diversification géographique : Présence multi-pays (Europe)
Mix produit équilibré : 3 catégories avec volumes similaires
Base client solide : 792 clients actifs

⚠️ Points d'Attention

Satisfaction préoccupante : 2,48/5 est faible
Distribution satisfaction : Trop de notes 0-1 (rouge)
Concentration : Grand Public domine potentiellement trop
Volatilité : Fluctuations importantes sur la courbe de ventes


💡 Recommandations
Priorité 1 : Satisfaction Client

Investiguer les causes des notes 0-1
Mettre en place suivi satisfaction systématique
Objectif : Atteindre 4/5 en 12 mois

Priorité 2 : Stabiliser la Croissance

Analyser les pics et creux de la courbe
Lisser la saisonnalité par des promotions ciblées
Objectif : Croissance plus régulière

Priorité 3 : Diversification Segments

Développer segment PME (actuellement sous-exploité)
Équilibrer dépendance au Grand Public
Objectif : Répartition 40%-30%-30%
